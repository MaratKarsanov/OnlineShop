# Online Shop
## О проекте
Online Shop — это интернет-магазин, разработанный на ASP.NET Core MVC. Основное приложение является монолитом, который взаимодействует с микросервисом отзывов. В проекте используются различные технологии и инструменты для обеспечения функциональности, производительности и мониторинга.

## Функциональные возможности
<h3>Основное приложение (монолит)</h3>
<ul>
  <li>Авторизация и аутентификация с помощью ASP.NET Core Identity.</li>
  <li>Логирование с использованием Serilog.</li>
  <li>Маппинг данных с использованием AutoMapper.</li>
  <li>Просмотр каталога продуктов, добавление в избранное и в корзину.</li>
  <li>Оформление заказа.</li>
  <li>Редактирование личного профиля пользователя, отображение заказов.</li>

  <li>Админ-панель:</li>
  <ul>
    <li>Создание, редактирование и удаление продуктов.</li>
    <li>Редактирование данных пользователей.</li>
    <li>Отображение списка всех заказов.</li>
  </ul>
  <li>База данных: PostgreSQL.</li>
</ul>
<h3>Кеширование</h3>
Использование Redis для кеширования данных каталога, что улучшает производительность и уменьшает нагрузку на базу данных.

## Тестирование
Unit-тесты для покрытия контроллеров, использовалась библиотека XUnit

## Установка и запуск
<h3>Предварительные требования</h3>
<ul>
  <li><a href="https://dotnet.microsoft.com/ru-ru/download">.NET Core SDK</a></li>
  <li><a href="https://www.postgresql.org/download/">PostgreSQL</a></li>
  <li><a href="https://redis.io/downloads/">Redis</a></li>
</ul>

<h3>Шаги установки</h3>
<ol>
<li>Клонируйте репозиторий:</li>

<code>git clone https://github.com/MaratKarsanov/OnlineShop.git
cd OnlineShop</code>

<li>Настройте строки подключения в файлах конфигурации для PostgreSQL и Redis.</li>

<li>Примените миграции базы данных:</li>

<code>dotnet ef database update</code>
<li>Запустите приложение:</li>

<code>dotnet run</code>
</ol>
